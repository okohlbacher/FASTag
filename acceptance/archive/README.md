# Held-out test records

Preregistrations (`PREREG-*.md`), freezes (`FREEZE*.md`) and results (`RESULT.md`) of FASTag's held-out
acceptance tests, copied as text from the test branches (`acceptance/1.12`, `acceptance/1.13`, `acc113r/*`,
`acc114/*`, `acc115/*`, `post1131/*-heldout*`) on 2026-11-18. Data and scripts stay on those branches.

Layout: `<branch>/<path on the branch, without the leading acceptance/>`. A file that is unchanged on several
branches is stored once, under the first branch in that order. `MANIFEST.tsv` lists every file on every
branch with the branch head commit, the git blob id and where it is stored here.
