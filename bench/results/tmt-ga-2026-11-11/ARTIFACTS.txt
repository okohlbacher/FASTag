Some audit scripts retain absolute paths to the frozen local/remote input data.
They are preserved analysis records, not a second general benchmark framework.
Raw mzML files and the complete tag TSVs are deliberately stored externally.
The raw peaks for the selected diagnostic cases are in audit/spectrum_support.json.
The complete audit archive also includes independent search tables omitted here;
audit/truth_audit_provenance.json inventories that archive, not just this subset.

Main reproduction:
  provenance/build-ga-v2.sh
  provenance/run-ga-v2.sh
  python bench/reuse_identical_scores.py PREVIOUS_RESULTS FINAL_RESULTS

The last command aborts on any changed output, reference, scorer, or repetition.
For changed outputs, score anew with bench/tmt_pseudo_filter.py --steps score
using the original manifest's datasets, binaries and settings instead of reuse.

Render from the repository root, with matplotlib and numpy installed:
  python bench/plot_tmt_ga.py bench/results/tmt-ga-2026-11-11
  python bench/plot_tmt_truth_cases.py \
    bench/results/tmt-ga-2026-11-11/audit/spectrum_support.json \
    bench/results/tmt-ga-2026-11-11/figures
  python bench/report_tmt_ga.py bench/results/tmt-ga-2026-11-11

Interpretation: the detector establishes evidence for TMT6/10 presence, not
labeling purity. Recall@50 and rank-1 refer to length-4 tags under the documented
sequence/flank rule, not downstream peptide-identification sensitivity or FDR.
