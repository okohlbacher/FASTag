## Needs a user decision (not blocking, but 1.0 should decide)

1. **Taxonomy distribution — 1(b).** Today: one shared `FASTag-taxonomy-k7.tar.gz`
   release asset (README documents it). Alternative: embed the ~232 MB index in
   every per-platform tarball (+~440 MB/release of identical bytes, but
   single-download installs). Decide before 1.0; the shared asset is the default.
2. **macOS signing.** The 7 `MACOS_*` secrets (reusable from BALL) are still not
   set on the repo; every tag build takes the "not configured" branch. Add them
   → signed+notarized `.dmg` per `doc/SIGNING-macos-gui.md`. Ship 1.0 unsigned
   or wait for secrets — user's call.
3. **F5** mass-shift localization: interoperate with PTM-Shepherd vs. skip for 1.x.
4. **F10** low-latency single-spectrum tagging (real-time use): build + benchmark, or drop from the roadmap.
5. **F11** glyco oxonium *flag* (not full glyco): cheap, but only worth it if a user exists.
6. **F12** top-N tags per spectrum for chimeric/DIA: `-max_tags` exists; a per-precursor top-N is a design decision.
7. **F14** overlap-friendly long reads for antibody assembly: nearly free given F4+F13, but needs a consumer (Stitch/ALPS) to validate against.

  The `gapped-tags` branch's GappedFiltration ingest (bitset-AND mass-window
  index; `doc/GAPPED-FILTRATION-INGEST.md`) is a candidate answer; its memory
  wall (~27 GB human) is the open question.

- **GUI React-side test harness** (vitest); Rust side is done.
- **`OnDiscMzPeakExperiment`** — belongs upstream in OpenMS; would delete the
  consumer here and bound mzPeak memory (currently ~11x file size upstream).
- **F13 remainder** (mzTab/mzIdentML/USI) — deliberately out of scope for a
  tagger; ProForma shipped.
